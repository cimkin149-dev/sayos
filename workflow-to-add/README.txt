This file is the GitHub Actions workflow that builds the SayMy OS ISO.
GitHub only lets you place it in .github/workflows/ from the website (or with a token that has the "workflow" permission).

To activate it (one minute):
1. Open workflow-to-add/build-iso.yml on github.com and click the pencil (Edit) icon.
2. In the file name box at the top, change the path to:   .github/workflows/build-iso.yml
   (click in the box, press Home, delete "workflow-to-add/" and type ".github/workflows/")
3. Press "Commit changes". The build starts by itself, or press Actions > Build SayMy OS ISO > Run workflow.
